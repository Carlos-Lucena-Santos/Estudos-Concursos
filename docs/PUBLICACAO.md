# Publicação no GitHub Pages
1. Revise a pull request e integre a branch feature/estudos-concursos-v0.1 à main quando desejar. Não há merge automático.
2. Em Settings → Pages do repositório, escolha Deploy from a branch, branch main, pasta / (root), e salve.
3. O index.html e seus módulos usam caminhos relativos, compatíveis com /Estudos-Concursos/.
4. Verifique a navegação na URL fornecida pelo GitHub. Nenhum servidor de aplicação ou chave é necessário.

A CI executa os testes do modelo; não publica automaticamente. Não versione a pasta privado/, backups pessoais ou PDFs de provas. Publicar a aplicação não publica o IndexedDB. Uma nova origem terá armazenamento separado; transfira dados com backup, se necessário.

GitHub Projects e Issues: use um quadro com colunas A fazer, Em andamento e Revisão. Sugestões de tarefas: receber arquivos oficiais; conferir permissões dos PDFs; revisar classificação das 180 questões; validar importação real. Não inclua dados pessoais em issues públicas.
